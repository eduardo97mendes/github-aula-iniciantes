# Como criar sua conta no GitHub

## Passo a passo

### 1. Acessar o site

Abra [github.com](https://github.com) no navegador.

### 2. Criar conta

1. Clique em **Sign up**
2. Digite seu e-mail
3. Crie uma senha forte
4. Escolha um nome de usuário (ex: `joao-silva-dev`)
5. Resolva o puzzle de verificação
6. Confirme seu e-mail

### 3. Personalizar (opcional)

O GitHub pode perguntar sobre seus interesses. Você pode pular essa etapa.

### 4. Verificar e-mail

Abra o e-mail de confirmação e clique no link enviado pelo GitHub.

## Dicas importantes

- Escolha um **nome de usuário** fácil de lembrar — ele aparece na URL dos seus projetos
- Use um e-mail que você acessa com frequência
- Guarde sua senha em local seguro

## Seu perfil

Depois de criar a conta, seu perfil ficará em:

```
https://github.com/SEU-USUARIO
```

Substitua `SEU-USUARIO` pelo nome que você escolheu.
