# Aula pelo navegador (computadores da escola)

**Use este guia se você está em um computador da escola, laboratório ou qualquer máquina pública.**

Na escola geralmente **não dá para instalar o Git** — pede senha de administrador. Tudo bem: **você não precisa instalar nada**.

Todo o conteúdo desta aula pode ser feito **direto no site do GitHub**, pelo navegador (Chrome, Edge, Firefox...).

---

## O que você consegue fazer só pelo navegador

| Atividade | Precisa instalar Git? |
|-----------|----------------------|
| Criar conta no GitHub | Não |
| Criar repositório | Não |
| Editar arquivos (README, Markdown) | Não |
| Fazer commit | Não |
| Criar README de perfil (portfólio) | Não |
| Ver histórico de alterações | Não |
| Criar arquivos e pastas | Não |

**Conclusão:** na escola, vá direto ao GitHub. Pule o arquivo [04-git-no-terminal.md](./04-git-no-terminal.md).

## Como editar arquivos pelo GitHub (resumo)

1. Abra seu repositório em [github.com](https://github.com)
2. Clique no arquivo (ex: `README.md`)
3. Clique no ícone de **lápis** (Edit)
4. Faça suas alterações
5. Role até embaixo → **Commit changes**
6. Escreva uma mensagem e confirme

Isso **já é um commit** — igual ao que faria no terminal, só que pelo site.

### Criar arquivo novo pelo site

1. No repositório, clique em **Add file** → **Create new file**
2. Digite o nome (ex: `apresentacao.md`)
3. Escreva o conteúdo
4. **Commit changes**

### Criar pasta pelo site

Ao criar arquivo, use barra no nome: `pasta/arquivo.md` — o GitHub cria a pasta automaticamente.

## Onde fica o trabalho do aluno?

**Na sua conta do GitHub, na nuvem** — não no computador da escola.

Quando você faz login no GitHub e edita pelo navegador:
- Os arquivos ficam salvos na sua conta
- Amanhã, em outro computador, é só fazer login de novo
- Nada se perde quando desliga o PC da escola

É como usar Google Docs: o conteúdo é seu, na nuvem.

## Cuidados em computadores públicos

Computadores da escola são compartilhados. Siga estas regras:

### Ao entrar
- Acesse [github.com](https://github.com) e faça **login na sua conta**
- **Não** salve a senha no navegador do computador da escola

### Ao sair da aula
1. Clique na sua foto (canto superior direito)
2. Clique em **Sign out** (Sair)
3. Feche o navegador por completo

Assim ninguém acessa sua conta depois de você.

### O que NÃO fazer na escola
- Não instalar programas (Git, editores) sem autorização
- Não deixar a conta logada
- Não compartilhar senha com colegas
- Não usar o computador da escola como único backup — seu projeto está no GitHub

## E o Git no terminal?

O Git no terminal é útil, mas **não é obrigatório** nesta aula.

| Onde | O que fazer |
|------|-------------|
| **Escola** | Só navegador — este guia |
| **Casa** (se quiser) | [04-git-no-terminal.md](./04-git-no-terminal.md) |

Na casa do aluno, com permissão para instalar, aí sim pode seguir o guia de instalação (Mac ou Windows).

## Perguntas frequentes

### "Perco meu trabalho se o PC da escola reiniciar?"
Não. Tudo que você commitou está no GitHub.

### "Preciso do mesmo computador na próxima aula?"
Não. Qualquer PC com internet e seu login no GitHub.

### "O professor consegue ver meu trabalho?"
Sim, se o repositório for **público** (recomendado para esta aula). Se for privado, só você vê.

### "Consigo fazer o README de perfil pelo navegador?"
Sim. Crie o repositório com o mesmo nome do seu usuário e edite o `README.md` pelo site — igual aos outros exercícios.
