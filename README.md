## Regra de ouro

> Nunca use nomes de exemplo literalmente.  
> `NOME-DO-REPO` é um placeholder — troque pelo nome real do seu repositório.

## Comandos essenciais

| Comando | O que faz |
|---------|-----------|
| `git clone URL` | Baixa o repositório para o seu computador |
| `git status` | Mostra o que foi alterado |
| `git add .` | Prepara todas as alterações para o commit |
| `git commit -m "mensagem"` | Salva uma versão com descrição |
| `git push` | Envia suas alterações para o GitHub |
