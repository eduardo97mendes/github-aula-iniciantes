# O que é GitHub?

## Conceitos básicos

| Conceito | Explicação simples |
|----------|-------------------|
| **Git** | Sistema que guarda o histórico de versões do seu projeto |
| **GitHub** | Site onde você guarda e compartilha seus projetos na nuvem |
| **Repositório (repo)** | Pasta do projeto no GitHub |
| **Commit** | "Foto" de uma versão do projeto com uma descrição |
| **Push** | Enviar suas alterações do computador para o GitHub |
| **Clone** | Baixar uma cópia do repositório para o seu computador |
| **Pull** | Baixar alterações que estão no GitHub para o seu computador |

## Analogia

Imagine que o **Git** é um caderno onde você anota cada mudança do projeto.  
O **GitHub** é a estante na nuvem onde esse caderno fica guardado e pode ser compartilhado.

## Para que serve?

- Guardar histórico de alterações
- Trabalhar em equipe no mesmo projeto
- Mostrar projetos no portfólio
- Publicar sites gratuitos (GitHub Pages)
- Participar de projetos open source
