# Primeiro commit pelo navegador

Nesta etapa você vai criar um repositório e fazer alterações direto no site do GitHub, sem usar o terminal.

## 1. Criar um repositório

1. No GitHub, clique no **+** (canto superior direito)
2. Clique em **New repository**
3. Preencha:
   - **Repository name:** `minha-primeira-aula`
   - **Description:** `Repositório de prática da aula de GitHub`
   - **Public**
   - Marque **Add a README file**
4. Clique em **Create repository**

## 2. Editar o README

1. Na página do repositório, clique no arquivo `README.md`
2. Clique no ícone de **lápis** (Edit)
3. Substitua o conteúdo por:

```markdown
# Minha Primeira Aula de GitHub

Olá! Meu nome é [SEU NOME].

## O que aprendi hoje
- Criar conta no GitHub
- Criar um repositório
- Editar um arquivo
- Fazer commit

## Meus objetivos
- [ ] Aprender Git básico
- [ ] Criar meu portfólio
- [ ] Trabalhar em equipe com código
```

4. Troque `[SEU NOME]` pelo seu nome real

## 3. Fazer o commit

1. Role a página até o final
2. Em **Commit changes**, escreva a mensagem:
   ```
   Adiciona informações pessoais no README
   ```
3. Clique em **Commit changes**

## O que aconteceu?

Você acabou de fazer seu **primeiro commit**! O GitHub salvou uma nova versão do arquivo com a sua mensagem de descrição.

## Conferir o histórico

1. Clique em **X commits** (ou na aba de commits)
2. Veja sua mensagem de commit na lista
3. Clique nela para ver exatamente o que mudou
