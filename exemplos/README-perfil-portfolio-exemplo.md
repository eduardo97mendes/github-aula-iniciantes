# Exemplo de README de perfil (portfólio)

Este é um modelo **simplificado** inspirado no perfil do professor ([eduardo97mendes](https://github.com/eduardo97mendes)), adaptado para alunos iniciantes.

O aluno deve criar um repositório com o **mesmo nome do usuário** do GitHub e usar este conteúdo no `README.md`.

---
