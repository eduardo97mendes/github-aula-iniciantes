# Exercícios da aula

## Exercício 1 — Perfil no README

Edite o `README.md` do seu repositório `minha-primeira-aula` e adicione:

- Seu nome
- Sua cidade
- Um hobby
- O que você espera aprender com GitHub

**Commit sugerido:** `Atualiza README com meu perfil`

---

## Exercício 2 — Arquivo de apresentação

Crie um arquivo `apresentacao.md` com:

```markdown
# Quem sou eu

- Nome:
- Cidade:
- Por que quero aprender GitHub:

# Meu primeiro projeto (ideia)

Descreva uma ideia simples de projeto que gostaria de colocar no GitHub.
```

**Commit sugerido:** `Adiciona minha apresentação`

---

## Exercício 3 — Lista de estudos

Crie um arquivo `estudos.md` com uma lista de 5 coisas que você quer aprender este ano.

Exemplo:

```markdown
# Minha lista de estudos 2026

1. GitHub básico
2. HTML e CSS
3. Python
4. Criar um portfólio
5. Trabalhar em equipe com Git
```

**Commit sugerido:** `Adiciona lista de estudos`

---

## Exercício 4 — Pelo terminal (desafio)

Se você configurou o Git no computador:

1. Clone seu repositório
2. Crie o arquivo `desafio-terminal.md`
3. Escreva dentro: `Consegui usar o terminal com Git!`
4. Faça `add`, `commit` e `push`
5. Confira no GitHub se o arquivo apareceu

**Commit sugerido:** `Completa desafio do terminal`

---

## Exercício 5 — Explorar o GitHub

No seu repositório, encontre e responda:

1. Onde vejo o histórico de commits?
2. Como edito um arquivo pelo site?
3. Qual é a URL do meu repositório?
4. O que significa "Public"?

---

## Critérios de conclusão

Você concluiu a aula quando:

- [ ] Criou conta no GitHub
- [ ] Criou o repositório `minha-primeira-aula`
- [ ] Fez pelo menos 3 commits
- [ ] Tem os arquivos `README.md` e `apresentacao.md`
- [ ] Sabe explicar o que é commit e push
